Claude API key

Rephraser calls the Claude API directly from your browser with your own key, billed to your Claude Console account. A claude.ai chat subscription (Pro, Max) does not include API access.

  1. Open platform.claude.com → API keys and create a key.
  2. Paste it above and choose Save & test.

The key is stored only in this browser profile and is sent only to api.anthropic.com. Web pages cannot read it.
